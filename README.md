# WayToFreedom

## 运行调试

Java 17 + Maven。运行 `src/main/java/yangjin/li/kline/KlineAnalysisMain.java` 的 `main`，即时使用 OkHttp 读取 OKX USDT 永续合约 K 线，在控制台逐根打印 MA5 变化率，命中金叉、死叉或趋平提醒时再输出详细信息。

默认使用 ETHUSDT 小时线，2026-10-18 00:00 至 2026-10-23 07:00。main 中手动调试只需两行：

```java
AnalysisRequest request = new AnalysisRequest(ContractSymbol.ETH_USDT, "2026-10-18 00:00", "2026-10-23 07:00", KlineInterval.HOUR_1);
testAnalysis(request);
```

参数顺序为币种、开始时间、结束时间、K 线周期。时间默认北京时间，按开盘时间首尾包含。`testAnalysis` 自动补取前置 10 根数据、调用 OKX 接口并分析打印；这是普通静态调试方法，直接运行 main，无需运行 JUnit。现有 main 同时保留四个命令行参数的调用方式。

- `ContractSymbol`：BTC、ETH、SOL、BNB 的 USDT 永续合约接口常量。
- `KlineInterval`：分钟、小时、日、周、月周期接口常量。`1m` 是一分钟，`1M` 是一个月。
- `MaCrossState`：均线位置、金叉/死叉、上涨/下跌趋平的接口常量。
- `TrendDirection`：待确认、上涨、下跌行情的接口常量。
- `Kline`：价格和成交量使用 BigDecimal，开始和结束时间使用北京时间 LocalDateTime。
- `testAnalysis(AnalysisRequest)`：只需传入查询参数，自动完成预热、拉取和分析。
- `fetchKlines(symbol, interval, start, end)`：按开盘时间筛选，首尾包含，返回正序、去重的 List<Kline>。
- `analyze(List<Kline>)`：逐根打印时间和 MA5 变化率，返回 void；历史不足或未收盘时变化率显示 `--`。

全部时间、日周月边界和显示均使用北京时间，不依赖电脑系统时区。日线从 00:00、周线从周一 00:00、月线从每月 1 日 00:00 开始。只使用确认收盘数据计算；未收盘记录会打印，但不产生提醒。

IDE 的项目 JDK 选 17。默认请求 https://www.okx.com；如网络需要其他可访问的 OKX HTTPS 服务地址，可配置 VM options。本机此前验证使用：

```text
-Dokx.baseUrl=https://www.okx.cab
-Dfile.encoding=UTF-8
```

保持 HTTPS 证书验证，无需交易密钥。命令行运行：

```sh
mvn package
java -Dfile.encoding=UTF-8 -Dokx.baseUrl=https://www.okx.cab -jar target/WayToFreedom-1.0-SNAPSHOT.jar
```

也可以传入四个参数：

```sh
java -Dfile.encoding=UTF-8 -Dokx.baseUrl=https://www.okx.cab -jar target/WayToFreedom-1.0-SNAPSHOT.jar ETHUSDT 1H '2026-10-20 17:00' '2026-10-23 07:00'
```

移动 jar 时保留旁边的 lib/。项目原有依赖及复盘资料保留。

## 本轮行情的调试规则

本版改用行情段的起点作为背景，不再用最新金叉或死叉交点的 2% 幅度来过滤趋平。

可调整的参数在 `KlineAnalysisMain` 顶部：

```java
MIN_TREND_MOVE_PCT = 2.0;   // 单位为百分比：走出 2% 后确认有效行情启动
TREND_RETRACE_RATIO = 0.50; // 单位为比例：回吐本轮累计幅度的 50% 后结束
DECELERATION_THRESHOLD_PCT = 70; // MA5 速度至少降低 70%；可手动改为 60、80 等
```

`TrendLegTracker` 同时维护上涨、下跌两套独立区域；两方向可以同时有效，均线金叉/死叉不重置任一区域：

| 方向 | 待确认的候选点 | 确认启动 | 有效期间的极值 | 结束条件 |
| --- | --- | --- | --- | --- |
| 上涨 | 最低收盘价 L | 从 L 上涨至少 2% | 最高收盘价 H | (H - 当前价) / (H - L) ≥ 50% |
| 下跌 | 最高收盘价 H | 从 H 下跌至少 2% | 最低收盘价 L | (当前价 - L) / (H - L) ≥ 50% |

每个方向有自己的起点、极值、确认时间和段编号。待确认期间持续更新候选点；确认后保持起点，遇到新推进极值才更新极值。达到 50% 时只结束本方向，以当前收盘价重新候选，不复用旧极值；另一方向继续按自己的规则更新。方向和编号共同标识本次回放内的区域，不保证与旧版本或不同查询范围一致。

例如 100→120→115 时，上涨仅回吐 25%，仍然有效，下跌从 120 已跌 4.17%，也已确认。再反弹至 117.5，只结束下跌（收复跌幅的 50%），上涨仍起于 100。下跌随后重新维护候选高点；若先涨到 118，再跌到 115.64，新下跌段从 118 起算，不复用旧高点 120。

50% 指本段推进幅度的一半，不是价格涨跌 50%；默认 2% 是区域启动门槛，不要求每次趋平之前额外完成新的 2% 推进。所有极值均为已确认收盘价，等价极值保留首次所属 K 线时间。起点所属 K 线和启动确认时间分开记录：只在达到启动门槛的当前根收盘后确认，不补发过去的提醒。

未确认 K 线会清除两个方向及形态状态，后续从已知数据重新确认，不跨未知区间保留旧区域。

## 趋平与提醒

几何趋平条件仍为：

```text
s = (当前MA5 - 上一根MA5) / 上一根MA5 × 100%
前三根 s 全部 > 0：上涨趋平
前三根 s 全部 < 0：下跌趋平
B = 前三根 |s| 的中位数
减速百分比 = (1 - |当前s| / B) × 100%
减速百分比 ≥ DECELERATION_THRESHOLD_PCT
等价条件：|当前s| ≤ B × (1 - DECELERATION_THRESHOLD_PCT / 100)
```

默认减速门槛为 70%，只剩原速度的 30%；60% 更宽松，80% 更严格，取值 (0,100]。不再设置 0.05% 的固定上限。前三根必须严格同方向，因此基准 B 一定大于零；零、混合方向或历史不足不会新进入候选段。

方向取自进入前三根的走势，不取决于本根变化率的正负。进入后固定方向、B 和阈值；小幅正负摆动仍属同段，离开阈值后才允许重新识别。开启行情过滤时，仅形态同方向区域结束才终止本段；另一方向结束不会重置本段或导致重复提醒。

- 上涨趋平：查询独立上涨区域，要求该区域已确认。
- 下跌趋平：查询独立下跌区域，要求该区域已确认。
- 对应区域待确认：不发趋平提醒；另一方向是否有效不阻断。普通行只显示时间和 MA5 变化率。
- 同段首次满足全部条件时提醒一次；若形态先出现、行情后来才确认，可以在之后首次满足时提醒。
- 2% 是启动确认门槛。一旦行情启动，后续不要求当前变化率始终大于 2%，由各自的 50% 回吐规则管理该方向是否仍有效。
- 金叉、死叉各自仍独立打印提醒，不受行情过滤影响。它们的估算交点与相对变化保留供观察。

三参 analyze 可调减速门槛，使用默认分段参数；四参还可调启动幅度；五参还可调回吐比例：

```java
analyze(klines, displayFrom, decelerationThresholdPct, startMovePct, retraceRatio);
```

调试时将 startMovePct 设为 0 可关闭行情过滤，隔离观察几何趋平；行情观察本身仍使用默认 2% 启动，避免零幅度除法。回吐比例必须在 (0,1] 内。

## 控制台对照

- 每根数据行：只显示北京时间的开盘时间和 MA5 变化率。不再输出候选延续、过滤原因或独立的 `[行情]` 日志。
- `[提醒]`：金叉、死叉、上涨趋平、下跌趋平。交叉提醒保留收盘价、MA5、MA10、变化率、均线位置及确认时间；趋平提醒还包含实际减速比例、减速门槛、速度阈值、金叉参考和同方向行情起点/极值/涨跌幅/回吐比例。
- 行情跟踪仍逐根计算，只减少日志；交叉、减速、去重和预热规则保持原样；区域资格改为双向独立。

例如 ZEC 日线 8 月 27 日：当前速度 0.34462%，前三根中位数 6.68736%，减速约 94.85%，通过 70% 的形态条件；8 月 26 日约减速 64.60%，默认不通过，改为 60% 后可通过形态条件。是否实际提醒还需结合行情方向和同段去重。

```text
2026-10-22 03:00  MA5变化率=-0.01868%
[提醒] ETH-USDT-SWAP 1H 候选段 #6；提醒类型=上涨趋平；所属K线=2026-10-22 03:00；收盘提醒时间=2026-10-22 04:00；收盘价=2493.31；MA5=2504.588；变化率=-0.01868%；…
```
- 候选编号包含被过滤的几何形态；四类提醒统计只计实际输出的提醒。行情编号仅在本次回放中有效。

以已核对的 ETH 小时线收盘价为例，20 日 17:00 的 2383.09 为起点，20 日 22:00 那根在 23:00 收盘确认上涨。中间 2450 附近的金死叉不重置起点。到 22 日 03:00 这根收盘时，极值为 2513.69，当前价 2493.31，段变化约 +4.62509%，回吐约 15.60490%，仍属于上涨段，可产生上涨趋平提醒。

## 历史与当前范围

`testAnalysis` 在请求范围前额外取 10 根，用于均线和初始状态预热。预热期只计算，不打印提醒。已在预热期满足完整条件的形态不会补发；显示期才首次满足的可以提醒。

有限历史不保证覆盖真实走势起点。改变查询开始时间可能改变早期分段和编号；想覆盖更早的起点，可手动提前开始时间。直接传给 analyze 的列表必须属于同一合约、同一周期且连续；错误、缺口、重复和混合序列会明确报错。

这是用于手动复盘的收盘价分段原型，尚未单独识别横盘平台、突破或成交量，也没有接入 ATR；均线交叉不重置行情并不代表所有横盘趋平都能过滤。只打印结果，不存储、不定时运行、不下单、不发送外部消息。

IDEA 若仍显示旧输出，先从磁盘重新加载源码并重新编译。Maven 项目名为 WayToFreedom，src/main/java 为正式源码，src/test/java 为测试源码，不要把整个 src 标成正式源码；右侧 Maven 面板可重新加载项目。
