# WayToFreedom

## K 线分析调试

Java 17 + Maven。直接运行 `src/main/java/yangjin/li/kline/KlineAnalysisMain.java` 的 `main` 方法，使用 OkHttp 即时从 OKX 获取 USDT 永续合约 K 线，控制台逐根打印 MA5、MA10、MA5 变化率、均线位置、交叉事件，以及相对最近一次已知金叉交点的涨幅。金叉、死叉、上涨趋平、下跌趋平均会单独打印提醒。

直接修改 `main` 中的四个参数即可：

```java
String symbol = ContractSymbol.ETH_USDT;
String interval = KlineInterval.HOUR_1;
LocalDateTime start = LocalDateTime.of(2026, 10, 18, 0, 0);
LocalDateTime end = LocalDateTime.of(2026, 10, 23, 7, 0);
```

- `ContractSymbol`：接口常量，预置 BTC、ETH、SOL、BNB 的 USDT 永续合约。
- `KlineInterval`：接口常量，包含分钟、小时、日、周、月周期；`1m` 是一分钟，`1M` 是一个月。
- `MaCrossState`：接口常量，分别定义 MA5 与 MA10 的当前位置、本根交叉事件和趋平方向。
- `Kline`：不可变 K 线实体，价格和成交量使用 `BigDecimal`；开盘、结束时间均为北京时间 `LocalDateTime`。
- `fetchKlines(symbol, interval, start, end)`：返回指定范围内正序、去重的 `List<Kline>`，按开盘时间筛选，首尾包含。
- `analyze(List<Kline>)`：返回 `void`，逐根打印分析结果；数据不足时明确标记。
- `analyze(List<Kline>, displayFrom, flatThresholdPct, slowdownRatio)`：可指定显示起点及阈值。

全部输入、实体、周期边界和输出统一北京时间，不依赖电脑的系统时区。日线从 00:00 开始，周线从周一 00:00 开始，月线从每月 1 日 00:00 开始；不提供 UTC 周期选项。`closeTime` 是结束的排他边界，例如 03:00 小时线的结束时间是 04:00。`confirmed` 对应 OKX 上游确认字段。

`main` 自动多取前面 10 根进行预热，只打印目标区间。10 根保证首根目标的 MA10 及上一根 MA10 可以计算；原有趋平判断只需 8 根预热，不会等待 MA10 数据才开始判断。

预热不保证恢复更早的全部交叉事件。如果最近一次金叉发生在已取数据之前，其交点及相对涨幅显示未知。程序不会为了寻找旧金叉自动向前扩大抓取范围；需要时可手动提前开始时间。

## 运行

IDE 导入根目录 `pom.xml`，项目 JDK 选择 17，运行 `KlineAnalysisMain.main`。默认请求 `https://www.okx.com`；如该地址无法访问，可在 VM options 设置其他可访问的 OKX HTTPS 服务地址。本机此前实测可用的参数为：

```text
-Dokx.baseUrl=https://www.okx.cab
-Dfile.encoding=UTF-8
```

保持 HTTPS 证书验证，不配置交易密钥。

命令行也可以运行：

```sh
mvn package
java -Dfile.encoding=UTF-8 -Dokx.baseUrl=https://www.okx.cab -jar target/WayToFreedom-1.0-SNAPSHOT.jar
```

或传入四个参数：

```sh
java -Dfile.encoding=UTF-8 -Dokx.baseUrl=https://www.okx.cab -jar target/WayToFreedom-1.0-SNAPSHOT.jar BTCUSDT 15m '2026-10-24 23:15' '2026-10-25 14:45'
```

移动运行 jar 时一起保留旁边的 `lib/` 目录。项目原有依赖和复盘资料保留。

## IDEA 重新加载 Maven

Maven 项目名称为 `WayToFreedom`。修改项目配置后，在右侧 Maven 面板点击“重新加载所有 Maven 项目”（双箭头刷新按钮），等待依赖同步完成，再运行 `KlineAnalysisMain.main`。

`src/main/java` 应为正式源码，`src/test/java` 应为测试源码。不要把整个 `src` 标记为正式源码；否则 IDEA 会用正式源码的依赖编译测试文件，导致 `org.junit.jupiter.api` 不存在。JUnit 保持 `test` 作用域，通过 Maven 测试验证；无需修改成正式依赖。

## 四种控制台提醒

四种事件都使用 `[提醒]` 行输出，并标记 `提醒类型=金叉`、`提醒类型=死叉`、`提醒类型=上涨趋平` 或 `提醒类型=下跌趋平`。所属 K 线以开盘时间命名，提醒时间为该根确认收盘时间。当前只打印到控制台，不向外部发送消息。

金叉和死叉是独立的交叉提醒，不需要先满足趋平条件。趋平也不要求 MA5 位于 MA10 的某一侧。同一根 K 线同时命中交叉和趋平时，分别打印两条提醒。

预热数据只建立状态，不打印提醒，也不计入显示范围的统计。分析结束时分别统计四种提醒数量；趋平候选段编号只累计本次显示范围新增的上涨或下跌趋平段，不包含金叉、死叉，也不表示完整上涨或下跌轮次。

## 当前趋平候选规则

```text
MA5 = 最近五根已确认收盘价的平均值
变化率 = (本根 MA5 - 上根 MA5) / 上根 MA5 × 100%

前三根变化率均严格为正：候选方向为上涨趋平
前三根变化率均严格为负：候选方向为下跌趋平
前三根混合正负或包含零：不进入新的候选段

B = 前三根变化率绝对值的中位数
当前变化率绝对值 ≤ min(0.05%, B × 30%)
```

阈值在 `KlineAnalysisMain` 顶部的 `FLAT_THRESHOLD_PCT` 和 `SLOWDOWN_RATIO` 调整。`0.05` 表示 `0.05%`。

上涨或下跌的标签由进入前连续三根的方向决定，不由当前变化率的正负决定。此前上涨、当前轻微下弯仍可能是上涨趋平；此前下跌、当前轻微上弯仍可能是下跌趋平。提醒中基准字段为“前3根绝对值中位数”。

进入候选段后固定该段阈值和方向，连续趋平只提醒一次。在阈值内小幅正负切换仍为同一段；离开阈值后再次满足完整进入条件，生成新候选段。在预热期已识别开始的候选只标记延续。

例如，ETH 小时线 2026-10-19 05:00 开始的 K 线在 06:00 收盘时，MA5 变化率约为 `+0.03647%`，此前三根约为 `-0.23309%`、`-0.32499%`、`-0.23846%`。此前连续下跌，绝对值中位数 `B = 0.23846%`，`B × 30% = 0.071538%`，取更小阈值 `0.05%`。当前绝对变化率小于该阈值，所以命中下跌趋平，即便当前变化率已经轻微转正。

未收盘 K 线会打印，但不参与本次收盘回放的均线和提醒计算。“收盘提醒时间”是历史回放中的可触发时间，不代表当时实际发送过消息。分页、缺口和上游错误会明确报错。

## MA5 与 MA10 信息

`MA10` 是最近 10 根已确认收盘价的平均值。逐根输出同时区分两类信息：

- 当前位置：MA5 高于 MA10、MA5 低于 MA10、重合或未知。
- 本根事件：金叉、死叉、无或未知。MA5 从下方穿到上方为金叉，从上方穿到下方为死叉；开头已经处在上方不会补造金叉。

连续重合时保留最后一次严格高于或低于的方向。触碰后回到原方向不产生事件；穿到另一侧时产生一次事件。如果穿越前连续多根重合，以最后一个重合样本为交点。

普通穿越的交点由前后两个收盘样本之间的均线线段估算。设前后两根的差值分别为 `d0 = MA5前 - MA10前`、`d1 = MA5后 - MA10后`，则：

```text
交点比例 = -d0 / (d1 - d0)
估算金叉值 = MA5前 + (MA5后 - MA5前) × 交点比例

价格相对涨幅 = (当前收盘价 - 估算金叉值) / 估算金叉值 × 100%
MA5相对涨幅 = (当前MA5 - 估算金叉值) / 估算金叉值 × 100%
```

估算金叉值是均线交点，不是当时实际成交价格。程序记录的是确认交叉的 K 线开盘和收盘时间，不计算盘中交叉时刻；历史回放只能在后一根确认收盘后识别该事件。

最近一次已知金叉作为涨幅参照，发生死叉后仍保留，直到新的金叉替换。它用于历史比较，不代表仍处于该轮上涨，也不用于完整上涨轮次编号。遇到未确认 K 线或无法形成完整 MA 窗口时，交叉状态和金叉参照重置；缺少数据的输入仍按原规则明确报错。

例如，此前 ETH 小时线样本中，2026-10-21 18:00 开始的 K 线在 19:00 确认金叉，估算交点约为 `2448.23475031`。2026-10-22 03:00 开始的趋平 K 线在 04:00 收盘时，MA5 为 `2504.588`、MA10 为 `2488.266`、收盘价为 `2493.31`；相对该交点，价格涨幅约 `1.84113%`，MA5 涨幅约 `2.30179%`。这是该历史样本的结果，其他区间的输出取决于实际数据。
